# 법인카드 근처 사용 분석

`python3 -m http.server 8000`을 실행한 뒤 브라우저에서 `http://localhost:8000`을 엽니다. 카카오 개발자 콘솔에서 JavaScript 키를 발급하고 카카오맵을 활성화한 뒤 웹 플랫폼에 `http://localhost:8000`을 등록하세요. 배포 시 실제 서비스 도메인도 등록해야 합니다.

지도 연결 후 기준 주소와 반경을 입력하고 UTF-8 CSV 또는 엑셀(.xlsx, .xls) 파일을 업로드해 분석합니다. 엑셀 파일은 첫 번째 시트를 사용하며, 엑셀 처리 라이브러리를 불러오려면 인터넷 연결이 필요합니다. CSV의 필수 열은 `이용일,가맹점명,가맹점 주소,이용금액`입니다. 화면에서 예시 양식을 다운로드할 수 있습니다. 주소는 카카오 주소 검색으로 좌표를 얻으며, 검색 실패 항목은 별도 표시됩니다. 거리는 직선거리입니다. 데이터는 서버에 저장하지 않지만 주소 검색 시 카카오에 주소가 전송됩니다.
