법인카드 근처 사용 분석

사용 내역과 기준 주소를 비교하여 가까운 결제를 살펴보세요.

1. 카카오 지도 연결

카카오 개발자 콘솔에서 웹 플랫폼 도메인과 카카오맵 사용 설정을 확인하세요. 키는 이 브라우저에 저장됩니다.

2. 분석 기준

직선거리 기준입니다. 주소는 위치 확인을 위해 카카오에 전송됩니다.

3. 카드 사용 내역

필수 열: 이용일, 가맹점명, 가맹점 주소, 이용금액
금액에 쉼표가 있다면 큰따옴표로 감싸주세요.

분석 결과

전체 내역0건
반경 내 사용0건
반경 내 금액0원
카카오 지도 연결 후 분석하면
기준 위치와 가맹점이 표시됩니다.
지도에서 가맹점 표시를 클릭하면 상세 내역이 표시됩니다.

거리 기준에 해당하는 내역은 확인 대상이며, 부정 사용 여부를 의미하지 않습니다.

사용 내역

사용일가맹점주소금액거리결과
CSV 또는 엑셀 파일을 불러와 분석해 주세요.
